# Matrice d'alignement

> Exigence EP-01 · Livrable L5 · Jalon J2.

**Discipline porteuse** : Technologie / Sciences de l'ingénieur · **Niveau** : Collège ou lycée · **Effectif** : · **Chapitre du programme officiel** :

| Objectif d'apprentissage observable | Compétence du programme | Activité de la séance | Modalité d'évaluation |
|---|---|---|---|
| 1. Écrire une instruction conditionnelle qui compare une mesure de distance à un seuil et déclenche une action | Algorithmique — structures conditionnelles | Modifier le seuil de déclenchement de l'évitement dans le code et observer l'effet sur le comportement du robot | Observation directe + relevé du seuil modifié dans le cahier de l'élève |
