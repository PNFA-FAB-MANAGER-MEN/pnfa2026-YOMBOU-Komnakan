## Raté, puis corrigé

- Le premier `commit` a échoué avec un message d'erreur → cause : les commandes `git config --global user.email` et `git config --global user.name` n'avaient pas encore été lancées, Git ne connaissait donc pas l'identité de l'auteur → correction : exécution des deux commandes de configuration, puis nouvelle tentative de commit → résultat : commit accepté, et après `push`, le dépôt GitHub était bien à jour

## Décidé
