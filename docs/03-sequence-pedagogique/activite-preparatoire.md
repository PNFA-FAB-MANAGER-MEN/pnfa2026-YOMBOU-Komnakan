# Activité préparatoire débranchée ou par blocs

> Exigence EP-06 · reliée au fonctionnement du dispositif (issue d'UC8-M2 ou M3).

**Objectif** : faire vivre la logique « mesure → seuil → décision » sans robot ni code, avant de l'observer sur le vrai dispositif.

**Déroulé (15-20 min)** : les élèves se mettent par deux. L'un joue le rôle du capteur : les yeux bandés, il avance à petits pas et annonce à voix haute une distance estimée à chaque pas (« trois pas », « deux pas »...). L'autre joue le rôle du programme : il a reçu une règle simple écrite sur une carte (« si la distance annoncée est inférieure à deux pas, dis STOP puis TOURNE »). Dès que la règle se déclenche, le binôme mime la manœuvre d'évitement.

**Lien avec le dispositif** : cette règle papier est exactement celle qui sera ensuite écrite en code (comparaison d'une distance mesurée à un seuil, déclenchement d'une action). L'activité rend visible, avant tout code, ce que fait réellement le capteur à ultrasons du robot.
